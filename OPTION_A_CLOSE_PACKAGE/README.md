## Core Close Thesis

Chris should not buy this as a website project.

He should buy it as the first owned revenue system AllSeason controls end to end:

- modern rebrand-ready website;
- native roof quote engine;
- secure Supabase lead intake;
- source-specific routing and scripts;
- Meta landing page loop;
- day-zero lead handling discipline;
- monthly owner scorecard tied to source economics.

The close is simple:

```text
You already know how to spend money on leads. Option A is how we make the spend accountable before you scale it again.
```

## Recommended Pitch Flow

1. Confirm the economic pain.
   - Roofing cannot carry a $3,000 job acquisition cost.
   - Shared lead dependency builds other brands.
   - High-intent leads need source-aware handling, not cold-call treatment.

2. Reframe the project.
   - This is not a design refresh.
   - This is the control point between demand and sold jobs.

3. Show the operating system.
   - Website and quote engine capture intent.
   - Supabase and routing preserve context.
   - Preview handling turns context into better first touches.
   - Reporting tells Chris what to scale, fix, or cut.

4. Ask for Option A.
   - $5,000 to build the owned asset.
   - $3,000/month to operate the first 90-day proof cycle.
   - Break clause after the first 90 days with 30 days notice.

## Close Criteria

Chris is ready to say yes when he agrees with these statements:

- "I want owned demand, not only rented lead flow."
- "I want high-intent leads handled differently from cold leads."
- "I want source-to-CAC reporting before I scale spend."
- "I want the new site to increase enterprise value, not just look better."
- "I want a 90-day proof cycle with clear owner decisions."
