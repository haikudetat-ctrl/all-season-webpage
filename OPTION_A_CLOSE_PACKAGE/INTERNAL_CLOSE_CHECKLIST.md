# Internal Close Checklist

## Before The Pitch

- [ ] Use latest deck: `allseason-owner-pitch-v3.pptx`
- [ ] Confirm whether buyer in meeting is Chris, Yuna, or both.
- [ ] Confirm 2Stack speaker roles:
  - Joe: business/economics, roofing context, close.
  - Chris: website, technical system, creative, implementation.
- [ ] Have Option A One-Page SOW ready.
- [ ] Have 90-Day Owner Scorecard ready.
- [ ] Have follow-up email drafted.

## Discovery Points To Reconfirm

- [ ] Current monthly lead spend by source.
- [ ] Current roof lead cost and sold-job CAC.
- [ ] Current contact rate and appointment set rate.
- [ ] Current response time for owned/vendor web leads.
- [ ] LeadMaster field/API constraints.
- [ ] Dialer shortlist and current CallTools setup.
- [ ] Hatch reliability concerns and current campaigns.
- [ ] CallRail numbers and offline attribution setup.
- [ ] Website domain plan for `.net`, `.com`, and future rebrand.

## Close Questions

Ask these before presenting price:

```text
Do you agree the first fix is control over the lead-to-sale path, not just more lead volume?
```

```text
Do you want the website treated as an owned acquisition asset instead of a brochure?
```

```text
If we can show source-to-contact-to-set-to-sale clearly, is that the kind of system you would put more money behind?
```

## Option A Close

```text
Our recommendation is Option A: $6,000 to build the owned system, $12,000/month to operate the first 90-day proof cycle.
```

```text
We are not asking you to commit forever. After the first 90 days, either side can end the retainer with 30 days notice.
```

```text
The first 90 days are about proof: what gets contacted, what gets set, what demos, what sells, and what should be scaled, fixed, or cut.
```

## Red Lines

Do not promise:

- guaranteed lead volume;
- guaranteed CPL;
- guaranteed closed jobs;
- guaranteed Google/Meta ad costs;
- warranty/legal claims without review;
- immediate CRM replacement;
- full rebrand execution inside Option A unless separately scoped.

Do promise:

- clear build scope;
- secure server-side intake;
- P0 routing for owned quote leads;
- source-specific scripts;
- tracking events;
- monthly owner scorecard;
- transparent recommendations.
